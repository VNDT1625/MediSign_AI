# Mobile Flutter

## Install deps

```bash
flutter pub get
```

## Run

```bash
flutter run
```

## Current foundation

- Onboarding + mode selector (`Hybrid/Local/Cloud`)
- Home shell with bottom navigation
- Emergency action button
- Consult and medicine screens backed by mock APIs

## Test / Lint / Format

```bash
flutter test
flutter analyze
dart format --output=none --set-exit-if-changed .
```
