# quy tắc.md

Muc dich: Bo quy tac bat buoc de giu codebase clean va dong nhat.

## Quy tac 1 - Bo file Markdown co dinh

Chi duoc su dung cac file .md co dinh sau:

1. status.md
2. learn.md
3. project.md
4. note.md
5. database.md
6. quy tắc.md
7. Required.md
8. Design.md
9. Tasks.md

## Quy tac 2 - Cam phat sinh file .md tuy bien

- Khong tu tao them file .md moi neu khong co phe duyet.
- Neu can ghi them noi dung, bo sung vao 1 trong cac file co dinh o tren.
- Ngoai le duoc phep: file workflow trong `.windsurf/workflows/*.md`.
- Ngoai le duoc phep: file workflow/skill trong `.vibecode/workflows/*.md` va `.vibecode/skills/*.md`.
- Khong tao file `.md` tuy bien ben ngoai root bo file co dinh, `.windsurf/workflows/`, va `.vibecode/workflows|skills/`.

## Quy tac 3 - Quy tac cap nhat

- Moi task xong: cap nhat status.md.
- Moi bug kho/sua kho: cap nhat learn.md.
- Moi quyet dinh lon: cap nhat project.md.
- Moi luu y conflict/rui ro: cap nhat note.md.
- Moi thay doi schema DB: cap nhat database.md.

## Quy tac 4 - Dong bo va review

- Moi PR phai kiem tra lai cac file tai lieu co can cap nhat khong.
- Uu tien dong bo tai lieu truoc khi merge.
